A recording guide for the website project and its JavaScript features.

The required student video has not been recorded. The project owner must record a 3–5 minute screen demonstration with their face visible, upload it publicly and replace the footer's Project video link on each page with that video's URL.

Recording checklist

  1. Open the Musicians page and show all 84 profiles loaded from the local JSON file.
  2. Open scripts/data.js and explain the asynchronous Fetch request, response check and JSON parsing.
  3. Open scripts/app.js and show the try/catch that displays an error message when loading fails. Demonstrate a failed request using browser developer tools.
  4. Demonstrate instrument and style filters, a saved favourite after a reload, and a musician dialog.
  5. Create a listening plan and show the submitted form values on its confirmation page.

See the site plan for the student's remaining sketch requirement.
